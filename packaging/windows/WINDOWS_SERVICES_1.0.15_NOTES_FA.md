# SOKNA Windows Services 1.0.15

Hotfix رابط فارسی Windows Services پس از تست واقعی 1.0.14.

- اصلاح متن فارسی وضعیت Runtime و Print Agent که در 1.0.14 به‌صورت mojibake نمایش داده می‌شد.
- اصلاح fallback نمایش نسخه Windows Services در حالت نسخه نامشخص.
- نسخه واقعی Runtime همچنان از executable نصب‌شده خوانده می‌شود.
- نسخه واقعی Print Agent همچنان از executable نصب‌شده خوانده می‌شود.
- Windows Runtime بدون تغییر: 1.0.2.
- Print Agent بدون تغییر: 6.2.9.
- Local/Public خارج از scope این hotfix هستند.
- gate انتشار اکنون وجود mojibake در سورس UI فارسی را fail می‌کند.
