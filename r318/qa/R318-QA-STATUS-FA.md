# R318 — ویرایشگر قالب چاپ، اصلاحات تجمعی QA (غیرقابل نصب)

این خروجی روی پایه R317 با استفاده از فایل JavaScript چاپِ اصلاح‌شده R311 ساخته شد؛ فایل‌های نصب‌شده کافه تغییر نکرده‌اند.

## آنچه در سورس انجام شد
- جلوی افزودن اجباری پاراگراف بلند «این برگه صورتحساب اولیه است…» گرفته شد. اما نوع سند `account_preview` و نشان «حساب باز · تسویه نشده» محفوظ است؛ این فیش نباید رسید پرداخت تلقی شود.
- عنوان اصلی چندخطی، زیرعنوان اختیاری و اندازه مستقل زیرعنوان؛ ویرایش و حذف کامل متن پایانی و کنترل نمایش سطر نحوه پرداخت در قالب مشتری.
- ترتیب اقلام آماده‌سازی طبق سفارش/بار اول/آشپزخانه اول، با متادیتای `station` و `order_index` بدون حذف هیچ قلم.
- طرح سه‌ستونی نام/تعداد/یادداشت برای کاغذ ۸۰ میلی‌متری؛ در ۵۸ میلی‌متری بازگشت به چیدمان دوستونی و یادداشت زیر قلم.
- انتقال فیلدهای ساده به بخش اصلی و نام/نسخه قالب به بخش بازشونده؛ پیش‌نمایش فوری با فونت، حاشیه، چیدمان و متن دلخواه همگام است.
- اصلاح اندازه پنل پیش‌نمایش در موبایل تا هنگام ویرایش ناپدید نشود.
- سورس Print Agent روی شاخه مستقل R318 در GitHub اصلاح شده، اما کامپایل ویندوزی آن انجام نشده است.

## آزمون
- ۱۷/۱۷ آزمون PHP قرارداد و ترتیب، ۱۷/۱۷ آزمون مرورگر؛ PHP lint و Node --check موفق.
- چهار تصویر قبل/بعد موبایل و دسکتاپ و یک تصویر تعامل مستقیم با پیش‌نمایش، همگی با HTML/CSS/JS واقعی و داده آزمایشی.

## موارد باز/محدودیت‌ها
- عدم دسترسی به ابزار کامپایل .NET و چاپگر واقعی: تأیید چیدمان چاپی و سازگاری با Print Agent نصب‌شده هنوز باز است.
- پیش‌نمایش فوری در مرورگر تقریبی است؛ پیش‌نمایش دقیقِ موتور چاپ پس از ادغام و اجرای واقعی Agent باید مجدداً آزمایش شود.
- انتخاب مستقیم قسمت‌های رسید با کلیک روی پیش‌نمایش هنوز انجام نشده است.
- این بسته نصب نیست و آزمون انتشار بنا بر تصمیم کاربر به پایان اصلاحات موکول شده است.
