# سامانه سکنا | گزارش R315 | فقط QA، غیرقابل نصب

**مبنای توسعه:** سورس تجمعی R314، شامل آثار R308–R314؛ نه سورس قدیمی شاخه اصلی.

## اصلاحات این مرحله

1. **تاریخچه فاکتور پابلیک** با دسترسی صندوق، فیلتر شماره و میز، مشاهده جزئیات، تفکیک روز فروش و روز پرداخت و متن پوشش محدود. داده فقط‌خواندنی است.
2. **حفاظت اطلاعات مالی:** برای کاربر فاقد مجوز صندوق نه endpoint تاریخچه و نه مدل خام گزارش نباید فاکتور خصوصی را برگرداند.
3. **گزارش مجموع نام مشابه** در Local و Public برای مثال «همه چای‌ها» در دسته‌های مختلف؛ عضویت بر مبنای کاتالوگ جاری، جمع بر اساس شناسه‌های واقعی کالا، محاسبه اسناد تسویه و برگشت.

## اعتبارسنجی

- PHP syntax و JavaScript syntax همه مسیرهای اصلاح‌شده: موفق.
- قرارداد تاریخچه ۱۸ مورد، گروه نام مشابه ۱۰ مورد: موفق. SQLite/MariaDB واقعی در این مرحله اجرا نشده.
- Playwright و CSS واقعی روی دو عرض موبایل و دسکتاپ: فهرست فاکتور، جزئیات و گزارش گروه نام؛ بدون خروج افقی و بدون خطای JavaScript.
- تصاویر صرفاً صفحه QA با داده ساختگی‌اند، نه اسکرین‌شات کافه یا تأیید چاپ.

## محدودیت و موارد باقی‌مانده

- آرشیو تاریخچه محدود است: حداکثر ۹۰ روز کاری اخیر/۲۴۰ سند؛ نه آرشیو نامحدود فاکتورها.
- گزارش «چای» فقط تطبیق متن نام است، نه گروه تحلیلیِ ذخیره‌شونده با تاریخچه انتساب کالا.
- API و همگام‌سازی دو میزبان، MariaDB و کنترل نقش‌های واقعی هنوز به آزمون نیاز دارند.
- سایر موارد دفتر ۱۳۰ عنوانی (از جمله چاپ پیشرفته، صدور ریالی و پوشش‌های مالی) هنوز بازند.
- **هیچ بسته نصب، انتشار، یا تغییر سیستم عملیاتی انجام نشده است.**
