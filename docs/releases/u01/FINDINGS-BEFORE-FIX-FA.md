# U01 — ثبت ایرادهای به‌روزرسانی قبل از اصلاح

تاریخ ثبت: ۲۳ اکتبر ۲۰۲۶. این سند پیش از تغییر کد موتور/پنل برای این درخواست ثبت می‌شود.

## مبنای بررسی
- انتشار قابل دانلود: Windows Services 1.1.22-keyless-rc.1؛ Supervisor/Engine 0.3.11.
- آخرین سورس درخواست حاضر: T01، شامل M06 اصلاح‌شدهٔ Local 231be، Guest Theme R2، CSS اصلاحی و اصلاح زمان/اعداد؛ ۷۵ migration، شامل 0074 جدید.
- بستهٔ T01 فقط سورس است؛ نصب روی خانه/کافه و آمادگی پنل واقعی با آن اثبات نشده است.

## موارد نیازمند اثبات

- استقلال واقعی از درایو و مسیر نصب، شامل فاصله و حروف فارسی؛ مبنای کشف از Apache/هویت نصب، نه مسیر ارسالی مرورگر.
- حفظ config، data، رسانه و هویت؛ صحت بکاپ و بازیابی در خرابی میان migration و تغییر اسلات.
- ادامهٔ عملیات پس از بسته‌شدن پنل یا راه‌اندازی دوبارهٔ سرویس؛ جلوگیری از اجرای تکراری.
- نتیجهٔ قابل مشاهدهٔ پنل پس از بازگشت Local و سازگاری schema/migration head در هویت نصب.
- خروجی انتشار فقط پس از آزمون‌های مناسب آماده اعلام شود؛ آزمون CI با نصب روی خانه/کافه یکی نیست.

هدف اصلاح: همان روند سادهٔ «یک ZIP در پنل → بررسی → نصب و نتیجهٔ روشن» با موتور موجود. کلید دستی، نصب‌کنندهٔ اختصاصی برای هر رایانه یا طراحی یک آپدیتر موازی اضافه نشود.
