# External Reviews

This directory contains independent review checkpoints. Reviews are evidence and
questions for the owning migration agent; they are not architecture decisions and
do not override `START_HERE.md`, approved handovers, ADRs, or explicit product-owner
requirements.

Before acting on a review finding, the owning agent must trace the relevant request,
historical behavior, V3 decision, and executable evidence. Intentional behavior
changes require the approval record demanded by `START_HERE.md`.
