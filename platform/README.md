# Platform

`platform` owns the approved infrastructure/runtime dependency lifecycle for SOKNA V3, including supported web stack/database/runtime prerequisites and machine provisioning.

Component independence does not require technicians to install every prerequisite manually. A SOKNA-managed bootstrap/platform lifecycle may provision approved dependencies while keeping Platform versioning and ownership independent from Local/Public application packages.

Platform must not own business logic or active Local application files beyond explicit bootstrap/deployment contracts.
