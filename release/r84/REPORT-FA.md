# سکنا R84 — بستن دو مورد اول ارتباط

تاریخ: ۱ نوامبر ۲۰۲۶. مبنا: بسته واقعی منتشرشده R83؛ زنجیره اصلی سورس Local/Public از Library حفظ شده است. سرویس‌های Windows تغییر نکرده‌اند. این بسته نامزد آزمایش خانه است.

## موارد اصلاح‌شده

**AUD-01: زمان Runtime در پابلیک سه‌ونیم ساعت جابه‌جا می‌شد.** زمان DATETIME محلی در مرز تولید heartbeat، پیش از امضای درخواست، به instant دارای offset تبدیل می‌شود. خروجی اصلی تشخیص Local تغییری نکرده است. آزمون با رسید واقعی MariaDB، منطقه تهران/UTC، تبدیل‌کننده واقعی HTTP پابلیک، تکرار تبدیل، نبود رسید و زمان آینده اجرا می‌شود. همان آزمون روی R83 شکست را نشان می‌دهد.

**AUD-02: مدل تازه ولی ناقص می‌توانست فهرست سفارش مهمان را خالی قطعی نشان دهد.** نبود نشست، فهرست خالی و نبود سفارش دارای رسید شناخته‌شده اکنون از Local مرجع خوانده می‌شوند. فهرست غیرخالی که رسید موردانتظار را دارد، همچنان از مسیر سریع مدل می‌خواند. هنگام خاموشی Local و نبود اثبات، خطا نمایان و فهرست قبلی حفظ می‌شود. هر دو کلاینت Guest، رسید فعال را برای بررسی کامل‌بودن مدل می‌فرستند و پاسخ نسل/نشست/رسید قدیمی را کنار می‌گذارند؛ پاسخ دیررس دیگر فهرست جدید را پاک نمی‌کند. خواندن مرجع ممکن است از مسیر سریع Projection کندتر باشد؛ کاهش زمان WAN واقعی در این انتشار ادعا نشده است.

آزمون PHP از مدل واقعی ذخیره‌شده در MariaDB می‌خواند؛ آزمون JavaScript تابع واقعی هر دو میزبان را با پاسخ وارونه، خطا، نشست جدید و رسید جدید اجرا می‌کند. این‌ها آزمون مرورگر کامل، شبکه هاست یا گوشی واقعی نیستند.

## محدوده تغییر

نسبت به R83 فقط چهار فایل اجرایی تغییر کرده‌اند: `RuntimeEvidence.php`، `GuestCompatibilityService.php` و `guest.js` هر دو میزبان؛ به‌علاوه شناسه‌های نسخه. SQL، CSS و طراحی دسکتاپ تغییر نکرده‌اند. اصلاحات R83 و R82 در بسته‌های مستقیم از R81 نیز حفظ شده‌اند.

## انتخاب بسته و نصب

نسخه مقصد Local: `3.0.0-g6.2-workspace.231ch-r84-causal-read-uat`

نسخه مقصد Public: `3.0.0-g3.6-workspace.35fr-r84-causal-read-uat`

Local و Public بسته‌های مستقل Delta دارند. فقط بسته مطابق نسخه نصب‌شده انتخاب شود؛ فایل‌های مبدأ مختلف پشت سر هم نصب نمی‌شوند. بسته‌ها یونیورسال نیستند و فقط مبناهای درج‌شده را می‌پذیرند.

| مؤلفه / نسخه مبدأ | فایل |
|---|---|
| Local R81 / 231ce | SOKNA-R84-LOCAL-R81-TO-R84-DELTA-HOME-UAT.zip |
| Local R82 / 231cf | SOKNA-R84-LOCAL-R82-TO-R84-DELTA-HOME-UAT.zip |
| Local R83 / 231cg | SOKNA-R84-LOCAL-R83-TO-R84-DELTA-HOME-UAT.zip |
| Public R81 / 35fp | SOKNA-R84-PUBLIC-R81-TO-R84-ROUTINE-DELTA-HOME-UAT.zip |
| Public R83 / 35fq | SOKNA-R84-PUBLIC-R83-TO-R84-ROUTINE-DELTA-HOME-UAT.zip |

بر مبنای آخرین Support موجود، خانه R81 است؛ اگر از آن زمان نصب دیگری انجام نشده، دو فایل مخصوص R81 کافی‌اند. ابتدا Public از Routine، سپس Local از Maintenance. فایل Emergency Full فقط جایگزین اضطراری است و برای مسیر عادی لازم نیست. داده‌های کسب‌وکار، صف چاپ و درخواست‌های مالی قدیمی در این انتشار دست‌کاری نشده‌اند.

پس از نصب، دو Support نزدیک به هم، زمان Runtime، ثبت سفارش/refresh سریع/پیگیری و فراخوان/پایان را روی یک میز آزمایشی بررسی کنید. بدون این شاهد، وضعیت «اصلاح و آزمون خودکار موفق؛ تأیید نصب باز» باقی می‌ماند.

## مواردی که هنوز بسته نشده‌اند

AUD-03 تنظیمات/قابلیت‌های سالن، AUD-04 اتصال صفحات جدید به Deferred، AUD-05 آماده‌بودن چاپ، بخش بازیابی AUD-06 و آزمون هم‌زمانی AUD-07 باز هستند. اختلاف مالی هفت‌روزه، سه درخواست قدیمی قلم جاافتاده و timeout متناوب هاست نیز بدون داده/Trace جدید بسته اعلام نشده‌اند. سیاست کنارگذاشتن آپدیت یونیورسال و مستقل‌بودن بسته Local/Public حفظ می‌شود؛ ساخت دوباره یونیورسال جزو این انتشار نیست.

این مرحله دو مورد اول را در سطح کد و آزمون می‌بندد؛ تمام ۲۳۳ تعهد یا پذیرش عملیاتی سامانه را بسته اعلام نمی‌کند.
