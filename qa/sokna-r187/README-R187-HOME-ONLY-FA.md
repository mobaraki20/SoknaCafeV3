# سکنا | Local R187 / 231ew — فقط Canary سیستم خانه

**کاربرد:** به‌روزرسانی Local از هویت دقیق نسخه فعلی سیستم خانه (`231ed`) یا دیگر مبدأهای دقیق موجود در فهرست ۵۶تایی. این فایل **یک ZIP مستقل برای بارگذاری مستقیم در پنل Local** است، نه ZIP مجموعه چند بسته.

## حدود تأیید

- سورس کارکردی از R184 با هش بایتی ثابت استخراج شده است؛ فقط `VERSION.txt` و دو فایل فراداده هویت و انتشار برای R187 تغییر کرده‌اند.
- R185: مهاجرت ۸۰→۸۱ در MariaDB، بازیابی پشتیبان در پایگاه مستقل و ۱۲ چرخه خطا/بازیابی موتور Maintenance تأیید شده‌اند.
- R186: Preflight، Stage، Activate، Readback نسخه، HTTP و مهاجرت دیتابیس در Windows واقعی آزمایشی، از مبدأ دقیق خانه، موفق شده‌اند.
- **شرط تحویل R187:** آزمون مجدد *عین همین ZIP* با هویت دقیق خانه، در Windows آزمایشی. گردش‌کار انتشار پس از موفقیت همه مراحل اجازه ساخت prerelease دارد.
- فایل نصبی Maintenance تغییر نمی‌کند. بررسی هویت دقیق منبع، پشتیبان امن پیش از اعمال، و برگشت از خطا همچنان در موتور Maintenance اجباری است.

## مهم

**این نسخه فقط برای Home Canary است و مجوز استفاده در سیستم عملیاتی کافه نیست.** آزمون عملیاتی خودِ دستگاه خانه، ارسال Push، Print Agent، و گردش‌های کامل تسویه/لغو سفارش هنوز تکمیل نشده‌اند. هیچ ادعایی مبنی بر رفع همه درخواست‌های عملیاتی وجود ندارد. اگر Preflight روی خانه به دلیل وضعیت واقعی پشتیبان یا هویت رد شد، فایل را مجدداً نصب نکنید و خطا را بررسی کنید. پاک‌کردن داده‌ها یا کلین‌اینستال لازم نیست.

**بارگذاری:** در پنل به‌روزرسانی Local فقط فایل با نام `SOKNA-R187-LOCAL-231EW-56BASE-HOME-CANARY-PANEL-UPDATE.zip` را انتخاب کنید؛ آرشیو GitHub Actions یا فایل SHA را انتخاب نکنید. قبل از نصب، پیام Preflight و وضعیت تهیه پشتیبان را بخوانید. از نصب روی کافه خودداری کنید.
