# R319 — ویرایش مستقیم از روی پیش‌نمایش فیش (QA، غیرقابل نصب)

**مبنا:** سورس دقیق R318 و وصله تجمعی R319؛ Local/Public عملیاتی بدون تغییر.

## انجام شد
- کلیک/لمس روی بلوک‌های پیش‌نمایش، تنظیم همان بلوک را باز و متمرکز می‌کند؛ راهنمای کوتاه و تأکید انتخاب دیده می‌شود.
- عنوان، زیرعنوان، تاریخ، شماره سفارش، ثبت‌کننده، ستون‌های اقلام، متن قلم، یادداشت، جمع نهایی، روش پرداخت و متن پایانی به کنترل‌های واقعی ویرایشگر وصل‌اند.
- انتخاب سرستون، چیدمان اقلام را باز می‌کند؛ انتخاب خودِ قلم، فونت اقلام را. فرم برای انتخاب از صفحه‌کلید Enter و Space نیز پاسخ می‌دهد.
- بازکردن جزئیات بسته، بازنشانی انتخاب هنگام تعویض قالب، حفظ نماینده انتخاب پس از بازسازی نمونه و تطبیق با رنگ/اجزای فعلی سکنا.
- این تعامل فقط DOM را تغییر می‌دهد؛ هیچ API ذخیره یا فرمان چاپ با لمس پیش‌نمایش اجرا نمی‌شود.

## آزمون‌ها
- ۴۴/۴۴ سناریوی Playwright در موبایل و دسکتاپ؛ دو بار تکرار موفق.
- ۹/۹ آزمون تطبیق قرارداد سورس، Node --check و PHP lint موفق.
- دو تصویر QA از خروجی واقعی HTML/CSS/JS در مرورگر؛ اطلاعات آزمایشی است.

## باز و ممنوع از ادعای اتمام
- C# Print Agent و تغییرات R318 در این محیط کامپایل نشده‌اند؛ dotnet موجود نیست.
- انطباق فیزیکی ۵۸/۸۰، اثر کاغذ و پیش‌نمایش دقیق Agent هنوز آزمون نشده است.
- آزمون کامل سامانه احراز هویت‌شده، یکپارچگی نهایی Local/Public، نصب و بسته انتشار به مرحله نهایی موکول است.
- باقی عناوین دفتر ۱۳۲ موردی بسته اعلام نمی‌شوند.

**وضعیت:** فقط کاندید سورس QA، **غیرقابل نصب**.
