# سامانه سکنا — دفتر به‌روزشده ایرادات Local / Public و برنامه آزمون تجمیعی

تاریخ: ۱۹ نوامبر ۲۰۲۶ | نقطه مبنا: **Local R278/231fn نصب‌شده در آخرین پشتیبانی کافه** | کاندید کد: **R293 + اصلاح سازگاری R294** | Public میزبان کافه: **35ij/R275** تا آخرین readback مستند. **هیچ نصب جدیدی روی کافه انجام نشده است.**

تفاوت وضعیت‌ها: «کد و QA موفق» به معنای بررسی سورس و آزمون آزمایشی است، نه قبول عملیاتی کافه؛ «جزئی» یعنی بخشی از سناریوها انجام شده؛ «باز» یعنی اصلاح در سورس تجمعی موجود نیست.

## موارد الحاقی مصوب، خارج از شماره‌های ۲۱‌گانه

- **NEW-PRINT-ALL:** «چاپ کل فیش آماده‌سازی» ثابت در ابتدای فهرست؛ کد و QA MariaDB یک‌کارچاپی موفق؛ چاپ فیزیکی Print Agent هنوز باز.
- **NEW-ITEMIZED-DISCOUNT:** تخفیف درصدی/ثابت فقط روی مانده پس از تسویه آیتمی؛ کد R293، سند immutable به‌ازای اقلام باز، MariaDB موفق؛ یک بار برای هر حساب و بدون برگشت تخفیف دوم.
- **NEW-TABLE-MOVE:** انتقال حساب دارای تسویه جزئی به میز خالی با همان session_id و ابطال public_token قدیمی؛ کد R293 و MariaDB موفق؛ رفتار Public/QR زنده باز.
- **NEW-QUANTITY:** افزودن سفارش جدید برای مصرف جدید، ویرایش تعداد فقط برای اصلاح اشتباه با قفل سهم پرداخت‌شده؛ مسیر QA به‌صورت محدود موفق؛ E2E کامل باز.
- **PUBLIC-ONLY-UX:** فاصله «اپ سکنا / نصب و تنظیمات دستگاه» و پیکان منو؛ مخصوص Public و خارج از بسته فعلی Local.

## ترتیب اجرا / گیت انتشار

**P0:** یک آزمون تجمیعیِ schema 82→83 با موتور واقعی Migrations، idempotence، full financial itemized + discount + table transfer، مانده حساب و رسیدهای immutable؛ سپس QA مسیر QR/Public و آزمون Windows Maintenance. **P1:** تکمیل لینک سفارش تاریخی، همسان‌سازی آماده‌سازی Public، اصلاح مجموعه چاپ ۱۰–۱۳ و ۱۶–۱۷، چاپ فیزیکی و آزمون نهایی مرورگرها. **P2:** تقویم رسمی، مرکزیت مودال، UX تب‌ها/آرشیو و فاصله منوی Public.

تا عبور از تست‌های native Windows/backup/restore، Public compatibility و چاپ واقعی، **NO-GO / NOT-INSTALL**. هیچ پاک‌سازی DB، صدور رسید واقعی یا تغییر تنظیمات کافه مجاز نیست.
